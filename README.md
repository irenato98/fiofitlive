# Fio Fit Live - página 6

Sitio estático recreado desde la página 6 del PDF proporcionado.

## Abrir localmente

Abre `index.html` en tu navegador o ejecuta:

```bash
python3 -m http.server 8000
```

Después visita `http://localhost:8000`.

## Publicar con GitHub Pages

1. Crea un repositorio.
2. Sube `index.html`, `styles.css`, `script.js` y la carpeta `assets`.
3. En GitHub abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.

## Antes de publicar

- Cambia los enlaces de redes sociales por los perfiles reales.
- El formulario ya está conectado al endpoint de Formspree `https://formspree.io/f/xrpzzbor`.
- Confirma y verifica el correo de destino dentro de tu panel de Formspree antes de publicar.
- Sustituye los textos legales demostrativos por documentos legales reales.
- Verifica que tienes autorización para usar las fotografías, logos y recursos del diseño.
